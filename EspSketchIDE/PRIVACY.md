# Privacy policy

_Last updated: 2026-09-27_

EspSketchIDE is an open-source app for writing and uploading Arduino sketches.
It is built for students, so it is designed to collect nothing.

## What the app stores

- **Your sketches** stay in the folder you pick on your device. The app can
  only read and write inside that folder, and only because you granted access.
- **Settings** (for example the editor text size) are stored privately on your
  device.

The app has no accounts, no analytics, no advertising and no crash reporting,
and it does not send your sketches anywhere.

## When the app uses the network

Current versions do not use the network at all. Planned versions will connect
to the internet only when you ask them to:

- to download an ESP32 **board pack** (compiler libraries) from this project's
  GitHub Releases, and
- to download the **Arduino library index** and the libraries you choose to
  install (from Arduino's and the library authors' servers).

Those servers see an ordinary download request (your IP address and the file
requested), as with any download. The app sends no identifiers of its own.

## USB devices

When you plug in a board, Android asks whether EspSketchIDE may use it. The app
only talks to the board to upload your sketch and to show its serial output.

## Children

Because the app collects no personal information, it is suitable for use in
classrooms.

## Contact

Questions or concerns: open an issue in the project's GitHub repository.
